# William's HQ

A personal life app: day plan, school, focus timer and countdowns. Runs on GitHub Pages; data lives in Supabase behind a login with row-level security, so this repo holds code only.

- `index.html`, `styles.css`, `app.js`: the app
- `plans.js`: the day plans (edit times and wording here)
- `config.js`: Supabase URL and publishable key (safe to be public)
- `sw.js`, `manifest.webmanifest`, `icons/`: home-screen install and offline shell
